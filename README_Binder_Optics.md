# Interactive Optical Bench — online JupyterLab

Educational interactive Python notebook exploring thin/thick lenses, mirror focal length, aperture stops, entrance/exit pupils, two-lens effective focal length, afocal telescopes, and Cassegrain telescopes.

**[Launch interactive JupyterLab in Binder](https://mybinder.org/v2/gh/kalyanradhakrishnan/astro-india/interactive-optics-binder?urlpath=lab/tree/Interactive_Optical_Bench.ipynb)**

Run the first imports cell; interactive sliders will appear in the subsequent cells. Each visitor gets a temporary independent computational session. The figures use paraxial first-order optics and are for teaching; these are not full non-sequential ray-tracing design analyses.

To run locally: `pip install -r requirements.txt` then `jupyter lab Interactive_Optical_Bench.ipynb`.
